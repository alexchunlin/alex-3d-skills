Drawing tools (use them instead of cropping and counting pixels): `D=/tmp/cgb-tools/drawing/draw`, `IMG=/tmp/cgb-data/{S}/input.png`. Coordinates are full-size sheet pixels (3072x2118, x right, y down); a BOX is x0,y0,x1,y1. Each command prints a few lines.

1. Read: `$D views $IMG` gives the view boxes. `$D text $IMG` (about 20 s, then cached) lists every dimension and note with its box, parsed: dia, radius, thread, angle, chamfer, linear; counts (4X, (6X)); THRU, TYP, DEEP. Treat it as the checklist of numbers to account for. You still decide which feature each number belongs to. OCR sometimes drops a Ø (Ø66.94 read as 66.94) or misses small vertical text, so look at the image when a value matters.
2. Scale: views on one sheet often have different scales. `$D scale $IMG --auto` prints px/mm clusters with the dimensions that agree and where they are. Use the cluster in your view, or calibrate from one dimension: `$D scale $IMG --p1 X,Y --p2 X,Y --mm V` with the points on its two extension lines (they snap to the lines), or `--circle X,Y --mm D` on a circle with a known diameter.
3. Measure what isn't dimensioned: `$D measure $IMG --scale S --origin X,Y --dist X1,Y1,X2,Y2 --circle X,Y --pt X,Y --snap`. `$D holes $IMG --crop BOX --scale S [--origin X,Y]` lists circles in mm, grouped into concentric sets (bore and counterbore) and patterns (PCD with start angle and step, grid, line). Check the count against the callout (4X, 6X).
4. Check orientation after every build: `$D overlay /tmp/cgb-run/{ARM}/{S}/output.step $IMG --crop BOX --scale S --view top|front|right|left|rear|bottom`. The view names are the render presets: top looks down from +Z, front from -Y, right from +X. It tries all 8 turns and mirrors of your part against the drawing view and prints OK, AMBIGUOUS or MISMATCH. A MISMATCH names the reading that matches better and the rotation that fixes your part. It also writes overlay_<view>.png next to the STEP: blue is your part, red the better reading. Run it on each view that has something asymmetric (an offset hole, the base, a notch). Use `--view all` if you aren't sure which side a drawing view shows. Fix every MISMATCH before you finish.
