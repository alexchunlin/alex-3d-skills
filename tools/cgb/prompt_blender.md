Tooling for this arm (required): headless Blender with the print-cad-blender skill. Read /Users/alxchunlin/code-stuff/alex-3d-skills/skills/print-cad-blender/SKILL.md and its reference/api.md and reference/footguns.md first (skip the assembly/checks.json parts; this is one part, not an assembly). Model with cadlib (geom, features) in a build script under /tmp/cgb-run/blender/{S}/, run it with `/Users/alxchunlin/code-stuff/alex-3d-skills/skills/print-cad-blender/scripts/cad build <script.py>`. Do not use build123d, CadQuery or OCP to model; they are reserved for the conversion step below.
Export: in the build script, after modelling, `exec(open('/tmp/cgb-tools/blender_export_world.py').read()); export_world(obj, '/tmp/cgb-run/blender/{S}/part.stl')` writes the mesh in world coordinates. Then convert: `/tmp/cgb-venv/bin/python -I /tmp/cgb-tools/stl2step.py /tmp/cgb-run/blender/{S}/part.stl /tmp/cgb-run/blender/{S}/output.step` (sews triangles into a faceted solid and merges coplanar facets). Curved faces stay faceted, so choose segment counts with that in mind.
